# Sentry и Django Silk в UrbanWear

## 1. Sentry

Sentry используется для мониторинга ошибок в проекте.

Если во время работы сайта возникает исключение, информация об ошибке может быть отправлена в Sentry.

Это помогает быстрее находить и исправлять ошибки в проекте после деплоя.

## 2. Настройка Sentry

В settings.py подключена библиотека sentry_sdk.

Sentry включается только если задана переменная окружения SENTRY_DSN.

Пример переменной:

SENTRY_DSN=https://example@sentry.io/project-id

Если SENTRY_DSN пустой, Sentry не отправляет ошибки.

## 3. Настройка traces_sample_rate

В settings.py используется параметр:

SENTRY_TRACES_SAMPLE_RATE

Он задаёт долю запросов, по которым собирается информация о производительности.

## 4. Django Silk

Django Silk используется для профилирования запросов.

Silk показывает:

- какие HTTP-запросы выполнялись;
- сколько времени занял запрос;
- какие SQL-запросы были выполнены;
- сколько времени заняли SQL-запросы;
- какие места можно оптимизировать.

## 5. Подключение Silk

В INSTALLED_APPS добавлено:

silk

В MIDDLEWARE добавлено:

silk.middleware.SilkyMiddleware

В urls.py подключен маршрут:

/silk/

## 6. Проверка Silk

Запустить сервер:

python manage.py runserver

Открыть несколько страниц сайта или API:

/api/products/
/api/categories/
/api/orders/

После этого открыть:

http://127.0.0.1:8000/silk/

В интерфейсе Silk будут видны запросы и время их выполнения.

## 7. Использование для оптимизации

Silk позволяет проверить, что в проекте используются select_related и prefetch_related.

Например, список товаров загружается с категориями и брендами через select_related.

Это уменьшает количество SQL-запросов и повышает производительность API.
